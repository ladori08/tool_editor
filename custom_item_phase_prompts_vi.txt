PHASE OVERVIEW — LỘ TRÌNH HOÀN THIỆN CUSTOM ITEM ENGINE
============================================================

Phase 0 — Audit & Stabilization nền cũ
Mục tiêu:
- Hiểu battle flow gốc.
- Xác định các hook item/move/ability.
- Fix các lỗi nguy hiểm trước khi mở rộng.

Phase 1 — Hook-based Custom Item Effect Engine Foundation
Mục tiêu:
- Tạo custom_effect_pool.json.
- Tạo effect_pool.py.
- Tạo hook_compiler.py.
- Compile effect theo hook/template/params.
- Implement 7 effect đầu tiên để prove engine hoạt động.

Phase 2A — Broad Item Effect Pool
Mục tiêu:
- Mở rộng effect pool cho nhiều item phổ biến.
- Thêm template an toàn cho item effects.
- Consumable/berry không làm mất custom item mặc định; dùng once_per_battle tracker.

Phase 2B — Ability Effect Pool
Mục tiêu:
- Mở rộng ability effects theo hook family.
- Mark partial/advanced rõ ràng.

Phase 2C — Move FunctionCode Effect Pool
Mục tiêu:
- Mở rộng move-derived effects dựa trên FunctionCode.
- Combined AfterMoveUse handler để nhiều effect không ghi đè nhau.

Phase 2D — UI/UX Refactor cho Effect Picker
Trạng thái cập nhật:
- Đã làm foundation: thêm Hook-based Effect Library UI với Search/Source/Status/Hook filters.
- Đã hỗ trợ chọn normalized pool effects trực tiếp và lưu qua selected_effect_ids.
- Đã giữ legacy Item/Move/Ability selectors để không phá item cũ.
- Còn lại: polish UI, selected effect configure panel, disable/cảnh báo advanced effects tốt hơn, tooltip/detail tốt hơn.
Mục tiêu:
- Thay dần UI chọn effect theo 3 cột Item/Move/Ability bằng UI hook-based.
- Source Item/Move/Ability chỉ là filter phụ.

Phase 3 — Runtime Safety & Backup/Restore
Mục tiêu:
- Đảm bảo runtime patch non-invasive.
- Backup/restore script data.
- Remove Custom Item Runtime Patch.
- Patch inspection/report.

Phase 4 — Advanced Item Effects
Mục tiêu:
- Implement những item effect phức tạp như Focus Sash, Air Balloon, Choice Lock full behavior.

Phase 5 — Advanced Ability Effects
Mục tiêu:
- Implement ability effects phức tạp như Intimidate, Moxie, Magic Guard, Wonder Guard, Prankster.

Phase 6 — Advanced Move/Battle-flow Effects
Mục tiêu:
- Implement Protect, Substitute, Trick Room, Transform, Encore/Taunt/Torment, multi-turn moves.

Phase 7 — Test Harness & Regression Pack
Mục tiêu:
- Tạo test matrix, custom test items, report pass/fail theo effect.

Phase 8 — Polish & Release
Mục tiêu:
- Hoàn thiện UI, import/export custom item packs, versioning, docs, release build.
